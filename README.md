# CS Vijay Makhija: website with admin panel

Upload every file in this folder to a GitHub repository, turn on GitHub Pages, then open `admin.html` on the live site.
Full step-by-step instructions are in the "Website Admin and Hosting Guide" document.

* `admin.html`, `admin.js`, `admin.css`, `admin/` : the private admin panel (works with a GitHub token)
* `content.json` : page text, links, colours and fonts (edited by the admin panel)
* `catalog.json`, `lectures.json`, `vault/` : encrypted notes and lectures (edited by the admin panel)
* `tools/protect.py` : optional command-line importer for many PDFs at once
